Instrucciones del archivo

El rizoma está restringido.

La experiencia comienza con una historia, hay que buscar claves dentro del recurso para liberar el rizoma. Completa cada tarea para abrir la siguiente tarjeta y ayudar a la comunidad a recuperar la red.

Tarjeta 01 · Mundo real

Evadir el sistema y encontrar las claves

Alma, Beto y Gera han burlado la seguridad y ocultado datos clasificados. Sigue estas instrucciones:

Fase 1: Accede a la tarjeta enlazada en "El umbral". Su visualización es obligatoria para que el sistema libere la tarjeta "Voces del Territorio".

Fase 2: Realiza la operación y obten el resultado.

Objetivo final: Descifrar la clave definitiva.

Tarea Sobrevive a la restricción, encuentra las pistas y descifra la palabra clave.
Al completar: se desbloquea Voces del Territorio.
Tarjeta 02 · Voces del Territorio

Reunir dos audios del territorio

Voces del Territorio solo recibe audios. Graba una evidencia de máximo 30 segundos sobre una problemática educativa cercana y acompáñala con una reflexión escrita.

Tarea Publica un enlace de audio válido. La comunidad debe reunir 2 audios.
Al completar: la tercera tarjeta queda desbloqueada.
Tarjeta 03 · Sobrecarga Visual

Sobrecarga Visual

Al completar los 2 audios se abre este espacio. Aquí puedes aportar texto limpio o video. La red conserva una última restricción: necesita 3 elementos (texto o video) para liberarse totalmente.

Tarea Comparte 3 elementos (texto o video) relacionados con las problemáticas del proyecto.
Al completar: se habilita la creación de nodos libres.
